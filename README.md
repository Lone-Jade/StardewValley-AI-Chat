# StardewValley-AI-Chat

基于 C# 和 SMAPI 的星露谷 NPC 对话模组。按游戏的人物 NPC 身份（`NPC.IsVillager`）动态接入，支持原版人物及采用该身份的模组人物，提供三条建议台词、自由输入、原生 NPC 回复和长期偏好记忆。

## 功能

- 两格内右键角色，打开对话、赠送、提交任务、人物信息和记忆菜单。
- 靠近并面向角色按 K，进入三条建议与自由输入面板。
- 为 47 名原版人物提供背景、说话风格、关系边界与知识范围参考，结合游戏当前关系及居所生成回复，详见[人物设定](docs/NPC_PERSONAS.md)。
- 支持 DeepSeek、Claude、OpenAI、MiniMax、Qwen、Kimi 的异步回复，等待期间支持取消，失败时回退本地对话。
- 按存档、玩家、NPC 和日期持久化去重，事件和节日期间保持剧情保护。
- 按存档、玩家和 NPC 持久化最近 6 轮成功展示的模型交流，后续请求携带近期上下文。
- 结构化长期偏好支持学习、纠正、撤销和遗忘，默认容量 32 条，跨六轮窗口与重新读档恢复。
- 记忆面板支持类别筛选、分页、来源与日期查看、手动纠正及三级遗忘，操作即时保存并显示结果。
- 模型回复同时提供下一轮三条玩家建议，下一次打开面板时使用。建议缺失或非法时补全一次，仍失败则使用本地模板。
- 每日首聊先显示原版 NPC 台词，读完后玩家回复，NPC 回应后结束。当天后续交谈由玩家发起。
- 普通 NPC 默认每天 5 轮，恋爱、订婚、婚后伴侣及室友默认不限，可通过 Generic Mod Config Menu 调整。
- 首次完成交谈按玩家台词与人物性格喜好的契合程度增加 0、10 或 20 点好感度，当天后续交谈不重复加分。

## 环境

已验证的环境为 Windows、Stardew Valley 1.6.15、SMAPI 4.5.2。模组目标框架为 net6.0，离线测试使用 net10.0，SDK 版本见 global.json。游戏和 SMAPI 需由开发者自行安装。

PowerShell 脚本优先使用项目内 `.tools/dotnet/dotnet.exe`，也支持 PATH 中的 dotnet。源码构建沿用 ModBuildConfig 的游戏路径检测，或通过参数、环境变量指定安装目录。

```powershell
./build.ps1 -GamePath $env:STARDEW_GAME_PATH
./test-offline.ps1
./run-dev.ps1 -GamePath $env:STARDEW_GAME_PATH
```

也可以将 `STARDEW_GAME_PATH` 设为自己的游戏目录，再执行上述脚本。开发实例只读取 `artifacts/Mods`，安装包输出在 `src/StardewValley-AI-Chat/bin/Debug/net6.0`。

## AI 配置

当前公测版本为 `0.1.0-beta.1`。将安装包中的完整模组目录放入实际启用的 Mods 目录。

默认使用 DeepSeek。复制 `config.example.json` 为 `config.json`，填写 `AI.ApiKey` 并将 `AI.Enabled` 设为 true。其他服务从 `ConfigTemplates` 选择对应完整模板。已有配置会将旧 `DeepSeek` 对象迁移到 `AI`。

模板包括 DeepSeek、Claude、OpenAI / ChatGPT、MiniMax、Qwen、Kimi 和通用 OpenAI 兼容接口，密钥均为空。Qwen 需要填写工作空间地址。字段、模型与官方资料见 [API 配置](docs/API_CONFIGURATION.md)。

升级时先退出游戏，备份本地配置和 Data 中的运行记忆，再覆盖安装包。模组采用项目身份 `StardewValleyAIChat.Core`，每日对话状态支持读取早期版本数据。近期交流与长期偏好的文件结构沿用 v2。

启用后，人物状态、玩家输入、近期交流及已启用的偏好记忆会发送到所配置的服务。请求失败时使用本地回退。输出预算和超时可在本地配置中调整。

## 操作

右键“对话”或按 K 打开面板。点击建议会填入输入框，可以继续编辑，点击发送或按 Enter 提交。Esc 或取消按钮关闭面板，等待中可取消请求。回复沿用原生 NPC 对话框。

每日首次交谈会先进入原版对话框，读完后自动打开回复面板。如果当天已通过其他原版入口交谈，则直接打开面板。原版特殊交互和问题对话沿用游戏自身流程，遇到其他菜单时停止自动衔接。

所有已出现且可接近的人物 NPC 共用右键和 K 入口。请求携带内部名、显示名、游戏提供的年龄阶段与性格资料、当前居所、玩家与人物的原生关系、原版开场及物品喜好。47 份原版人物参考档案随 DLL 内嵌，每次只注入当前人物，游戏资料优先；心数不独立代表恋爱或婚姻。缺少档案的模组人物使用游戏资料与通用角色指引。原生非社交人物有当前台词时先展示该台词，否则直接进入玩家面板，其对话次数与记忆分别记录，好感度结算按 `CanSocialize` 判定。

Abigail、Sebastian、Leah 使用专属本地对话池，其他人物使用 `Data/Dialogues/Default.json` 作为接口失败或关闭时的回退。可添加 `<NPC内部名>.json` 覆盖通用池。显式存在的专属池若格式错误，会记录错误并停用该人物对话池。通用池的去重仍按各 NPC 身份分别保存。

Windows 中文输入可单独安装 Input Method Fix。已在测试环境与 1.0.7 版本共同验证输入正常，该项目使用 MIT 许可证。[Input Method Fix 源码](https://github.com/Cyrillya/InputMethodFix) · [Nexus Mods 下载页](https://www.nexusmods.com/stardewvalley/mods/35313)

## 每日上限与好感度

安装 Generic Mod Config Menu 后，在 StardewValley-AI-Chat 设置页调整普通 NPC 和伴侣的每日上限，范围为 0 到 100，0 表示不限。没有安装配置菜单时，可直接编辑 config.json 中的 `DailyDialogueLimit` 和 `PartnerDailyDialogueLimit`，重启游戏生效。已有配置会补入默认值。配置菜单的“默认”按钮恢复每日上限、长期记忆选项和输出预算，API Key 继续使用本地已配置值。[GMCM 项目](https://github.com/spacechase0/StardewValleyMods/tree/develop/framework/GenericModConfigMenu)

每名 NPC 分别计数，成功展示一次 NPC 回复算一轮，本地回退也计数。只读原版开场、编辑、取消、走远或过期请求不消耗次数。达到上限时提示次日再聊，伴侣范围依据当前玩家的恋爱、订婚、结婚或室友关系判断。

首轮由模型结合当前玩家台词、原版开场、人物性格和游戏提供的喜爱物品评为三档。明显冒犯或贬低喜好为 0 点，普通礼貌或中性回应为 10 点，真诚且具体契合人物性格喜好为 20 点。评分缺失、非法或模型失败时为 0 点。成功展示回复后结算，当天后续对话不会补发或叠加奖励。当天已通过原版入口取得交谈奖励时，模组不再额外加分。

每日流程、次数和奖励标记放在当前玩家的 modData 中，随游戏正常存档一起保存，确保计数与好感度回档一致。近期交流仍在独立 JSON 中即时保存。

```text
stardewai_status Abigail
stardewai_dialogue Leah
stardewai_ai Sebastian 最近有什么有趣的事？
```

## 记忆与建议

模组目录下的 `Data/ConversationMemory` 保存按身份隔离的 v2 JSON。每个记录包含最近 6 轮玩家和 NPC 的台词、最新的三条建议、长期偏好和历史过滤标记。每次成功修改递增版本序号，写入失败后缓存不会暴露未提交的数据。每日台词去重继续保存在 `Data/DialogueHistory`。

仅在生成回复通过校验并成功显示后追加记忆，取消、过期和失败请求保持轮数不变。本地回退台词使用原有去重规则。生成失败时清空待显示的模型建议，下一次面板使用本地模板。退出到标题和读档会清理内存缓存，后续按存档身份恢复文件内容。

每个文件通过同目录临时文件替换完成原子写入。损坏、无法读取或无法写入的记忆会暂停该身份的 AI 请求并记录错误，本地对话仍可使用。若需重置记忆，先退出游戏，再删除对应身份文件。安装包排除这些运行数据。

### 长期偏好

玩家明确表达“我最喜欢向日葵”“我喜欢雨天”等偏好后，模型可以提出记忆更新。程序验证当前玩家原话的完整分句，并过滤提问、假设、转述和模糊表达。仅在有效回复成功展示后，将偏好、六轮交流和建议一次写入。模型提供的记忆 ID 不参与修改目标定位。

支持花、天气、食物、饮品、季节、活动、动物和颜色八类，以及最爱、喜欢、不喜欢三种类型。每类一个最爱，普通喜欢和不喜欢可有多个值。明确撤销记为 retracted，后续请求会告知模型该偏好已经撤销。有效记录可信度由程序固定为 1.0。

“我现在最喜欢玫瑰，但仍喜欢向日葵”可替换最爱并保留普通喜欢。模型更新协议支持 ADD、REPLACE、REMOVE、FORGET，每轮最多三项，非法批次整体忽略。缺失记忆更新字段时仍可正常展示回复。建议补全仅采用补全后的建议，偏好更新采用首个有效回复。

GMCM 提供长期记忆、学习新偏好、自动更新已有偏好和调试日志开关，以及 1～100 条的容量设置。默认开启长期记忆、学习和更新，容量 32，调试日志关闭。撤销记录计入容量，满额时提示新增未保存，修改和删除仍可执行。降低容量保留已有记录，请求按最近更新时间选取，最多携带 32 条。

关闭长期记忆后停止注入和模型修改，已有文件保留。学习开关控制新增条目，自动更新开关控制已有条目的纠正、重复确认和撤销。长期记忆开启时，明确遗忘独立于这两个开关，管理命令始终可用。

### 查看与遗忘

右键人物选择“记忆”，左侧点击类别按钮循环筛选，使用左右翻页按钮浏览，每页六条。选中记录后可查看类型、有效或撤销状态、来源原话、游戏日期和 UTC 时间，长原话使用“下一页”查看。

右侧点击类别、类型和状态按钮切换，点击内容框输入 1～80 字，点击“保存纠正”提交。手动编辑保留记录 ID、初始日期和原始证据，并标记为手动纠正。相关旧值、新值所在的近期交流会从后续请求中排除，待用建议清空。接受相反立场时撤销冲突立场；同类别的第二个最爱或重复偏好会提示编辑已有记录。

“遗忘这一条”“遗忘当前类别”“清空全部”均有确认步骤。当前类别以左侧筛选类别为准，选择“全部类别”时使用当前选中记录的类别。保存、遗忘和重新读取会取消待处理请求；记录版本已变化时刷新数据并要求重新操作，写入失败则显示错误并暂停写入，修正文件后可“重新读取”恢复。Tab 切换焦点，Enter 激活或在输入框中保存，Esc 返回或关闭。

在 SMAPI 控制台执行以下命令，NPC 使用内部名，类别使用 flower、weather、food、drink、season、activity、animal、color。

```text
stardewai_memory list Leah
stardewai_memory forget Leah <记忆ID>
stardewai_memory forget-category Leah flower
stardewai_memory clear Leah
stardewai_memory reload Leah
stardewai_memory reload
```

`list` 省略 NPC 时默认 Abigail，显示条目 ID、类别、类型、状态和内容。单条遗忘保留原始交流，发送请求时过滤包含被遗忘值的玩家台词、NPC 台词或历史建议所在的整轮，混合话题轮次也会暂时排除。过滤信息随文件保存，随轮次滚出六轮窗口清理，当前三条建议会失效。

类别遗忘清除对应偏好及该 NPC 的六轮交流和建议。全部清空清除该 NPC 的全部记忆和上下文。自然语言“忘记我喜欢什么花”“忘记我的全部偏好”也可通过模型提出对应范围的操作。

`reload NPC` 重新加载当前玩家与该 NPC 的记录，可用于修正文件后的恢复。省略 NPC 时清理全部记忆缓存。修改记忆、重新加载和记忆配置变更会取消待处理请求，回复展示前及提交时都会检查身份和版本，迟到响应会被丢弃。

v1 文件在读取时迁移到内存，首次成功写入 v2 前在同目录保留一次 `.v1.bak`。原有六轮交流继续参与近期上下文，长期偏好从之后成功的明确交流中建立。记忆文件上限 256 KiB，运行数据和备份均由 Git 与安装包排除。
