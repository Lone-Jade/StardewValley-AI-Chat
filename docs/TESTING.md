# 公测验证说明

## 构建与离线验证

安装 global.json 指定的 .NET SDK，运行以下脚本。构建时由 ModBuildConfig 检测游戏目录，也可通过 STARDEW_GAME_PATH 指定游戏安装目录。

```powershell
./test-offline.ps1
./build.ps1 -GamePath $env:STARDEW_GAME_PATH
```

离线回归覆盖以下行为。

- 对话池校验、天气与好感度筛选、权重边界、同日去重及换日恢复。
- 异步单请求、取消、场景过期、请求身份及记忆版本检查。
- 三条建议、输入面板状态、六轮历史与长期偏好持久化。
- 明确偏好提取、混合提问、多项偏好、纠正、撤销、三级遗忘和上下文过滤。
- 容量、身份隔离、数据迁移、原子写入和失败恢复。
- 记忆管理分页、编辑、确认、焦点及过期视图处理。
- 47 份人物档案、内部名匹配、关系与居所上下文，以及原生性格映射。
- 多服务请求格式、响应解析、配置迁移、空密钥及失败处理。

## 公测操作

1. 安装 SMAPI，将完整模组目录放入 Mods，选择服务模板并填写本地密钥。
2. 在游戏实际进入中文语言环境后加载测试存档，靠近 NPC，使用右键菜单和 K 打开对话。
3. 首次交谈读完原版开场，发送一条自由输入，检查回复、三条建议与每日次数。
4. 输入一项明确偏好，换题交流后再次询问，再测试纠正与遗忘。
5. 等待回复时打开菜单、走远、切换地点或返回标题，检查取消和迟到响应。
6. 测试赠送、任务交付、人物信息与记忆入口，并检查关闭面板后可以移动。
7. 正常过夜并重新加载，检查次数重置、偏好保留和首聊奖励。

## 反馈内容

反馈中提供游戏、SMAPI、模组版本、服务名称、模型、NPC、复现步骤和屏幕现象。提交日志前删除密钥、账号信息、存档身份及本机绝对路径。可用模拟台词替代私人对话。

模型仍可能遗漏偏好、猜测事实或偏离人物语气。公测反馈需要保留具体触发输入，以便复现。人物与剧情组合、多人房屋，以及重写原版人物的模组需要扩大验证。
